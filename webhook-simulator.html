    7️⃣ Webhook Events Reference

    These events are simulated and logged. In production, Stripe sends these via HTTPS webhook:

    payment.success

    { "id": "evt_test_success", "type": "charge.succeeded", "data": { "object": { "id": "ch_1234567890", "amount": 5000, "currency": "usd", "customer_email": "user@example.com", "metadata": { "bookingId": "booking_123", "cleric": "Shaikh Ahmad" } } }, "timestamp": "2026-08-26T14:00:00Z" }

    charge.refunded

    { "id": "evt_test_refund", "type": "charge.refunded", "data": { "object": { "id": "ch_1234567890", "refunded": true, "refunds": { "total_count": 1, "data": [{"id": "re_123", "amount": 5000}] } } } }
