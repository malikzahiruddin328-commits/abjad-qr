🔐 Two-Factor Authentication
Setup & Configuration Guide

How 2FA Works

Two-Factor Authentication (2FA) adds a second layer of security. After entering your password, you'll need to enter a 6-digit code from your authenticator app.

Uses Time-based One-Time Password (TOTP) standard — compatible with Google Authenticator, Authy, Microsoft Authenticator, etc.

Authenticator Apps

Compatible apps:

  • Google Authenticator (iOS, Android)
  • Microsoft Authenticator (iOS, Android)
  • Authy (iOS, Android, Windows, Mac)
  • FreeOTP (iOS, Android)
  • LastPass Authenticator (iOS, Android)
